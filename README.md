# Nintimer

[English](README.en.md)

**発表中に、時間のことで気を取られないようにするタイマーです。**

投影する画面の隅に小さく重なるので、スクリーンから目を離さずに時間が分かります。時間が来ても音も点滅も出さず、スライド送りのキーにも触れません。開始時刻と終了時刻を入れておけば、開始を押す必要もありません。

発表者向けの画面（PowerPoint の発表者ビューなど）が使えない会場でも使えます。

> **いまは無料の公開βとして配っています。** 気づいたことがあれば、公式サイトの問い合わせ窓口からお知らせください。分かっている問題は[既知の問題](known_issues.md)にまとめています。ここは Nintimer の**ポータブル版**の配布元です。Microsoft Store 版は <https://apps.microsoft.com/detail/9N7LCWZ81GSC> から入れられます。公式サイトは <https://poola-vii.github.io/nintimer/> です。
>
> このリポジトリはポータブル版を配るためのもので、**Nintimer のソースコードは含みません**（ソースは非公開です）。

## できること

- **発表の邪魔をしない** — 小さく半透明で、時間が来ても音も点滅も出しません。出すのは時間と色と細いバーだけで、「待機中」のような文字も出しません。
- **時刻で決まった枠なら、開始を押さなくていい** — 「13:00〜13:30」のように、設定画面で開始時刻と終了時刻を入れて「OK」を押しておけば、13:00 になると自分で計り始めます。数字は現在時刻で、残りは細いバーが示します。休憩中に入れておけば、発表の始めに開始を押し忘れる心配がありません。
- **スライド送りのキーに触れない** — キーボードの入力を奪わないので、スライド送りの操作はそのままプレゼンソフトに届きます。タイマーはマウスだけで操作できます。
- **全画面のスライドショーの最中でも操作できる** — タイマーを右クリックすれば、開始・一時停止・設定ができます。邪魔になったらドラッグで動かせます。
- **予定どおりにいかない発表にも** — 持ち時間とカウントアップでは、始まらなかった発表を、右クリック → 一時停止 → 開始 で 0 から測り直せます。終わったら一時停止すると、止めた値が残ります。
- **3つの測り方** — 持ち時間（例: 20分）、開始時刻と終了時刻（例: 13:00〜13:30）、カウントアップ。時間を過ぎると赤に変わり、持ち時間では `+03:05` のように超過時間を数えます。
- **日本語と英語** — Windows の表示言語に合わせて出ます。設定画面で選ぶこともできます。

## 動作条件

| | |
|---|---|
| OS | Windows 11（64 ビット、x64）で動作を確かめています。ARM と 32 ビットの Windows には対応しません |
| .NET | **不要**です。実行に必要なものは同梱しています |
| プレゼンソフト | LibreOffice Impress の全画面のスライドショーで動作を確かめています |
| 表示倍率 | 100%・150%・200% で動作を確かめています |

ほかの環境の状況は[既知の問題](known_issues.md)の表にあります。

## 入手する

### Microsoft Store 版（おすすめ）

<https://apps.microsoft.com/detail/9N7LCWZ81GSC>

Microsoft Store で「Nintimer」を探して入れてください。更新は Store が行います。**Smart App Control がオンの PC では、Store 版をお使いください。**

### ポータブル版（このリポジトリ）

**Store が使えない PC 向けです。** インストールは要りません。`nintimer.exe` を好きな場所に置いて実行してください。

- 入手先: このリポジトリの [Releases](https://github.com/poola-vii/Nintimer-releases/releases)
- 更新の知らせ: Releases の Atom フィード（`https://github.com/poola-vii/Nintimer-releases/releases.atom`）、このリポジトリの Watch、[変更履歴](CHANGELOG.md)。**アプリからは通信しないため、アプリが更新を知らせることはありません。**
- ほかの人に紹介するときは、ファイルを渡すのではなく、このページか公式サイトを教えてください。ほかの人から受け取ったファイルは、下の「入手したファイルを確かめる」で本物かどうかを確かめてから使ってください（配り方の決まりは[利用条件](terms.md) §4）。

**ポータブル版には署名を付けていません。** そのため次のことが起きます。

- **初回起動時に「WindowsによってPCが保護されました」という警告が出ます。** 「詳細情報」を押して「実行」を選ぶと起動します。
- Smart App Control がオンの PC では起動できません。Store 版をお使いください。

#### 入手したファイルを確かめる

ダウンロードしたら、配布元のものと同じか確かめてください。PowerShell で次を実行し、表示された値が下の表と同じであることを見ます。

```pwsh

```

| 1.0.1 | `nintimer.exe` | `4398E5AFA19ACA2D06961CF7A78F9833EC9699482F5E04D377375D8B3A1712F3` |

値が違うときは使わないでください。

## 最初に使うとき

1. `nintimer.exe` を実行します（Store 版はスタートメニューから起動します）。
2. 画面の右上に小さなタイマーが出ます。タスクトレイにもアイコンが出ます。
3. タイマーかトレイのアイコンを右クリックして「設定...」を選び、持ち時間などを決めて「OK」を押します。
4. 発表を始めるときに、タイマーをダブルクリックするか、右クリックして「開始」を選びます（開始時刻と終了時刻で指定したときは、「OK」を押したときから時間枠が有効になるので、開始の操作は要りません）。
5. 終わったら、右クリックして「一時停止」を選ぶと、止めた値が残ります（持ち時間とカウントアップのとき）。

**表示の言語**: Windows の表示言語が日本語なら日本語、それ以外は英語で出ます。設定画面のいちばん下の「言語 / Language」で決めることもできます。言語を変えて「OK」を押すと、計時は最初からになるので、発表の前に決めてください。

**最初は自動で起動しません。** 発表のときに起動してください。

設定は `%APPDATA%\nintimer\config.json` に保存されます。ポータブル版をやめるときは、`nintimer.exe` とこのフォルダーを削除してください。
